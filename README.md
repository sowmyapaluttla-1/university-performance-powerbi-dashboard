# 📈 University Performance & Student Enrollment Dashboard

## 📌 Project Overview

I built an interactive Power BI dashboard to analyze
student applications, enrollments, conversion rate,
fee collection, academic performance and faculty distribution.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📈 Key KPIs

- Total Applications
- Total Enrollments
- Conversion Rate
- Total Fee Collection
- Average Marks
- Pass Percentage

## 🔄 Data Preparation

Power Query was used for data cleaning and transformation.

## 💡 Key Insights

- Enrollment trends
- Course performance
- Department performance
- Fee collection trends
- Academic performance
- Admission agent performance
